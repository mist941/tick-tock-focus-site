Privacy Policy

Effective date: 2026-10-05

Summary

  • TickTockFocus doesn't collect any personal data.
  • Nothing is sent to the developer. The extension makes no network requests.
  • No data is sold or transferred to anyone.
  • Your presets stay in Chrome's own storage. If you turn on Chrome Sync, Google syncs them between your browsers.

Scope

This policy covers the TickTockFocus Chrome extension and this website, ticktockfocus.com.

What is stored and where

The extension keeps a small amount of data in Chrome's extension storage so that it can work. It never sends this data anywhere itself; the only way it leaves your browser is Chrome Sync, if you turn it on.

Data stored by TickTockFocus
Data Where it's kept Leaves this browser?
Your presets (each preset's name and steps) and settings (12- or 24-hour clock) Where it's kept

chrome.storage.sync

If Chrome's sync storage limits are reached, the item is kept in chrome.storage.local instead, and the extension tries to move it back to sync later.

 Leaves this browser?

Only through Chrome Sync. When it's on, Google syncs this data to the other Chrome browsers where you're signed in. Chrome Sync is governed by Google's Privacy Policy.

When Chrome Sync is off, it stays in this browser.
The running timer (its end time, total length, and a copy of the preset's name and steps) and the preset you last selected Where it's kept

chrome.storage.local

 Leaves this browser?

No. It stays in this browser.

Permissions and why they're needed

storage
Saves your presets and settings, and remembers the running timer so it keeps going when you close the popup or restart Chrome.
alarms
Wakes the extension at the end of each step, even when the popup is closed.
notifications
Shows a notification when each step ends and when the whole routine is finished.

The extension has no host permissions and no content scripts, so it can't read or change any website.

What the extension doesn't do

  • It makes no network requests. Chrome Sync, if you turn it on, is handled by Chrome itself.
  • No analytics, telemetry, or tracking of any kind.
  • No ads.
  • No cookies.
  • No account or sign-in.
  • No access to the websites you visit, your browsing history, or the content of any page.

Your control over your data

  • Delete a preset: in the Presets tab, select the × button next to it. The preset is removed from the extension's storage and, when Chrome Sync is on, from your other synced browsers too.
  • Stop syncing: turn off Chrome Sync in Chrome's settings. Presets you save after that stay in this browser.
  • Clear the running timer: pressing Stop clears its state. It's also cleared when a run finishes.
  • Uninstall: removing the extension deletes its local data (chrome.storage.local) from this browser. To remove synced presets from your other browsers too, delete them in the extension before you uninstall it.

This website

ticktockfocus.com is a static site. It uses no cookies, no analytics, and no JavaScript, and it doesn't load anything from other websites: styles and images come from this site, and text uses your device's own fonts.

The site is hosted on GitHub Pages. GitHub may process technical data, such as your IP address, to deliver the site and keep it secure. See the GitHub General Privacy Statement.

Links to other sites, such as the Chrome Web Store and GitHub, lead to pages covered by those sites' own privacy policies.

Chrome Web Store User Data Policy

The use of information by TickTockFocus complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. The extension uses the data described above only to provide its features. The data is never sold, never used for advertising or to determine creditworthiness, and the developer never has access to it.

Changes to this policy

If this policy changes, the new version will be posted on this page with a new effective date. Every earlier version is available in the history of this page on GitHub.
